# Bangalore Rental Price Predictor — Start Here

You do NOT need to know machine learning before starting this project.

We will build this project in small checkpoints:

1. Set up the project folder and confirm Python packages work.
2. Download the rental dataset and put it in `data/raw/`.
3. Inspect the raw data.
4. Clean the data.
5. Restrict the data to Bangalore + the six project localities.
6. Create useful features.
7. Do EDA with Pandas, Matplotlib and Seaborn.
8. Train Linear Regression.
9. Train Random Forest.
10. Compare models using RMSE and R².
11. Build an approximate rent range from validation errors.
12. Add SHAP explanations for an individual prediction.
13. Build the Streamlit app.
14. Test the app locally.
15. Push everything to GitHub.
16. Deploy to Streamlit Community Cloud.
17. Finish the README and resume-ready project description.

IMPORTANT:
- Do not skip checkpoints.
- Do not edit files we have not reached yet.
- Keep the raw dataset unchanged.
- Save cleaned data separately.
- Never commit secrets, passwords or API keys.

Project localities:
- Whitefield
- Koramangala
- HSR Layout
- Indiranagar
- Electronic City
- Marathahalli

The final app is a decision-support tool, NOT a live property marketplace.
